## Screenshots on Windows

On Windows, use Snipping Tool or similar app to select a rectangle (or window).
Then copy the screenshot to the clipboard and paste it, or save it as a file.

## Screenshots on Mac

On a Mac, use keyboard shortcuts (several options):

- Copy the **Entire Screen** to the Clipboard:
  Press Command (⌘) + Control (⌃) + Shift + **3**.
  This captures the entire screen and copies it to the clipboard.
- Copy a **Selected Portion** of the Screen to the Clipboard:
  Press Command (⌘) + Control (⌃) + Shift + **4**.
  This allows selecting a portion of the screen to capture.
- Copy a Specific **Window** to the Clipboard:
  Press Command (⌘) + Control (⌃) + Shift + **4, then press the Spacebar**.
  Move the camera icon over the window to capture, click,
  and the screenshot will be copied to the clipboard.
- **All options**: Press Command (⌘) + Shift + **5** to open the screenshot toolbar,
  with several options.
