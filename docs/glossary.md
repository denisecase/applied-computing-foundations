# Know These Terms

## Operating Systems & Environments

- **Operating system** - software that provides a computer's core functions,
  including managing hardware, files, and applications
- **System files** - files required by the operating system and not intended to be modified by users

### Popular operating systems

- **Windows** - a widely used operating system developed by Microsoft
- **macOS** - an operating system used on Apple computers (Macs)
- **Linux** - an open-source operating system commonly used on servers and development systems

### Administrator Privileges

- **Administrator** - a user account with elevated permissions to create, delete, or modify
  system settings and files

---

## Command Line

### Terminal vs Shell

- **Terminal** - a text window where you type commands to the computer
- **Shell** - the program inside the terminal that interprets your commands
  (for example, PowerShell on Windows, zsh on macOS, bash on Linux)

### GUI vs Command Line

- **GUI** - a graphical user interface often used with a mouse
- **Command line (CLI)** - working by typing commands rather than clicking

---

## Files & Folders

### Organizing Files

- **Folder / directory** - a container used to organize files on a computer
- **Path** - the address of a file or folder (for example, `C:\Repos` or `~/Repos`)
- **Current folder (working directory)** - the folder the terminal is "in" right now

### File naming

- **File name** - the full name of a file, including its extension
  (or the portion before the extension when context is clear)
- **File extension** - the suffix at the end of a file name that indicates file type
  (for example: `doc`, `xls`, `md`, `html`)

### Hidden (by Default)

- **Hidden files & folders** - files & folders not shown by default in file managers

---

## User Interfaces

- **Context menu** - a menu that appears when right-clicking (or control-clicking) an item
- **Windows File Explorer** - the graphical interface used to browse files and folders on Windows
- **Finder** - the graphical interface used to browse files and folders on macOS

---

## Version Control and Repositories

### Git and GitHub

- **Git** - a tool that records project history
- **GitHub** - a website that stores project repositories online

### Project Repositories

- **Repository (repo)** - a folder that Git tracks, including its history

### Git Commands

- **git clone** - make the first local copy of a GitHub repository
- **git add** - add files so git manages them
- **git commit** - save a snapshot of changes to local history
- **git push** - send local commits up to GitHub
- **git pull** - bring changes down from GitHub to the computer
